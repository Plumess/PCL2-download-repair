# 0.3.6

首次公开发布：一次修复，以后继续使用原来的 PCL 图标。

## 使用体验

- 自动识别附近已适配的正式版、赞助快照版和 PCL CE x64。
- 保留原 EXE、已有快捷方式、Minecraft 目录、账号和启动设置。
- 恢复原版下载、整合包拖入、手动导入、启动自动导包和在线安装入口，沿用 PCL 的原生页面、任务与安装器。
- 使用自绘标题栏和青绿色界面，提供“恢复原状”入口。
- 内置签名适配更新；网络可达时后台准备，下次正常启动生效。

## 本次发布

- README 使用首次打开状态的界面预览，附新手教程和支持范围。
- 用户包包含最新版说明、界面图片、发布说明和许可证，所有文件路径使用英文。
- GitHub Actions 自动编译、打包、校验、签名并发布，源码包严格按公开清单生成。

普通用户下载 `PCL2-download-repair-release-0.3.6.zip`；名字带 `-source` 的 ZIP 是开发者源码包。

当前验证环境为 Windows 10 x64；CE ARM64 不在支持范围。适配取决于启动器的方法结构，结构大改或引导入口被清除时仍可能需要新版工具。无法访问 GitHub 时继续使用本地组件。具体已验证版本与操作说明见 README 和 USER-GUIDE.md。
