# 第一次用：跟着这几步做

你只需要先修复一次。修复完成以后，继续点原来的 PCL 图标。

修复不会替你换 Minecraft 文件夹，也不会重新配置账号、版本选择或启动参数。你原先的游戏和设置继续保留。

## 1. 下载并解压

下载作者发布的 **`PCL2-download-repair-release-<版本号>.zip`**，例如 `PCL2-download-repair-release-0.3.6.zip`。版本数字会变化，选择当前最新版即可。

右键点击这个 ZIP，选择 **“全部解压”**。打开解压后的文件夹，找到里面的 **`PCL2-download-repair` 文件夹**。

不要下载名字带 `-source` 的压缩包；那个是源码，给开发者看的。也不要直接在 ZIP 里面双击程序。

## 2. 把文件夹放对位置

找到你平时用来打开 PCL 的程序，把整个 `PCL2-download-repair` 文件夹放到它旁边。

放好后应该大致像这样：

```text
你的 PCL 文件夹
├─ Plain Craft Launcher 2.exe    ← 你原来的 PCL，名字可能不同
├─ PCL                          ← PCL 自己的资料文件夹
└─ PCL2-download-repair               ← 这次放进来的文件夹
   ├─ PCL2-download-repair.exe
   ├─ README.md
   └─ USER-GUIDE.md
```

注意：`PCL2-download-repair` 和 PCL 程序放在同一层，不要放进上图那个 `PCL` 资料文件夹。

只知道桌面图标在哪？右键那个图标，选择“打开文件所在的位置”，通常就能找到原程序。

## 3. 运行一次修复

1. 先关闭 PCL。正在玩的 Minecraft 游戏可以继续开着。
2. 打开 `PCL2-download-repair`，双击 **`PCL2-download-repair.exe`**。
3. 等待工具识别并处理旁边的启动器。
4. 看到 **“已完成接入”**，就可以关闭修复工具。

如果旁边有多个 PCL，工具会分别处理并显示结果；无需你先判断是正式版、赞助快照版还是 CE。

如果提示没找到 PCL，点 **“选择 PCL”**，选中你原来的 PCL 程序即可。如果提示 PCL 还开着，关掉它，再点“重新检查”。

修复工具自己不包含启动器。选中的应该是你的原 PCL，不能选 `PCL2-download-repair.exe`。

## 4. 以后照常使用

继续用你原来的桌面图标、任务栏图标或 PCL 程序打开启动器，不用每天再点修复工具。

- 下载原版：打开 PCL 顶部“下载”，进入“原版游戏”。
- 导入整合包：把 ZIP 或 MRPACK 文件拖进 PCL 窗口。
- 手动选择整合包：进入整合包页面，使用导入按钮选择文件。
- 在线整合包：点击版本行开始安装；单独的保存／另存为按钮仍用于保存文件。

RAR 报不支持时，先解压，再把内容重新压缩成 ZIP。把 `.rar` 改名成 `.zip` 不算重新压缩。

## 朋友怎么用

把 **修复工具 ZIP** 发给朋友，让朋友按上面步骤放到**他自己的 PCL**旁边运行一次。

不需要发送你整个 PCL 文件夹。朋友继续使用他自己的启动器、账号和设置。

## PCL 更新后

如果你以前装过早期测试包，先下载 `0.3.6` 或更新的完整修复包，再按上面的步骤运行一次，统一引导组件和更新配置；以后普通更新不用反复做这一步。

一般继续照常打开即可。引导入口还在、方法结构仍兼容时，会重新适配更新后的程序。

在线适配更新在已配置的发布通道下后台运行。GitHub 无法连接时不会阻止 PCL 启动，也不会因此关闭已经可用的本地修复。

本包已经记住更新仓库 `plumess/PCL2-download-repair`，会后台检查已发布的签名更新。不需要填写地址、登录 GitHub 或提供令牌；暂时连不上时，继续使用本地修复。新组件下载并校验通过后，在下次正常打开 PCL 时使用，不会强关你的 PCL 或游戏。

如果更新后提示“需要新的适配”，先保留修复文件夹，联网时会后台重试。若新版提示必须更新引导工具，再下载新版修复工具运行一次。

## 想还原成没有补丁的样子

1. 关闭 PCL。
2. 打开 `PCL2-download-repair.exe`。
3. 点 **“恢复原状”**，等待完成。
4. 照常打开原来的 PCL。
5. 不再需要时，再删除 `PCL2-download-repair` 文件夹。

**不要把顺序反过来。** 如果直接删掉组件，PCL 可能还在寻找被删除的文件。

误删后打不开也可以处理：重新解压修复工具，放回原位置，运行“恢复原状”或重新修复。

## 没成功时先看这里

| 看到的提示或情况 | 怎么处理 |
|---|---|
| 没找到 PCL | 检查位置，或点“选择 PCL” |
| PCL 还开着 | 关闭 PCL，再点“重新检查”；不用关闭游戏 |
| 已有其他启动扩展或 `hostfxr.dll` | 先按原扩展的说明恢复，避免两个工具互相覆盖 |
| 原版入口出现，但列表加载失败 | 先看 PCL 显示的网络或下载源错误；出现入口不等于网络请求一定成功 |
| 新版本需要适配 | 使用维护者的新适配器或新版工具 |
| CE 提示缺少 .NET 运行时 | 先解决原 CE 自己的运行条件；修复包不附带 .NET 运行时 |

要反馈问题时，说明 PCL 版本、执行了哪一步、看到的错误文字。修复工具日志在 `PCL2-download-repair/.local/logs`，不需要发送整个游戏文件夹。
